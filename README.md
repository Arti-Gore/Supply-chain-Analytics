Supply Chain Analytics Dashboard
Project Overview

This project analyzes supply chain data using Python and Power BI to understand sales, revenue, manufacturing costs, shipping costs, and supplier performance.

Tools Used
Python
Pandas
NumPy
Matplotlib
Power BI
Key Insights
Revenue analysis by product type
Product sales analysis
Supplier performance analysis
Manufacturing cost and lead-time analysis
Shipping cost and transportation analysis
Defect rate and stock-level analysis
Project Files
supply chain analysis.pbix — Power BI dashboard
supply_chain_Analysis (1).ipynb — Python analysis notebook
Objective

To analyze supply chain data and generate useful insights for business decision-making
